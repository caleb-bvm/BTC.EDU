Cómo interpretar los datos

La actividad se registra desde {% if data.first_event_at %}{{ data.first_event_at|date:'d/m/Y H:i' }}{% else %}que exista el primer evento{% endif %}. No se reconstruyen visitas anteriores. Sin denominador se muestra «Sin datos».

El periodo puede incluir sesiones o compras incompletas. Las métricas de actividad anteriores al inicio del registro tienen cobertura parcial. Una sesión usa un identificador aleatorio, sin direcciones IP ni correos. No identifica a una persona entre dispositivos.

Completar una lección, abrir contenido o aprobar una evaluación son resultados diferentes. Las cifras registradas no acreditan aprendizaje ni validación comercial.
