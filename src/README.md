# BTC.EDU

Plataforma educativa con contenido gratuito y compras mediante facturas Lightning en entornos locales de prueba.

La documentación se mantiene en cuatro archivos:

- [Informe principal](../strategy/19-recomendacion-y-entrega-final.md): idea, investigación, producto, desarrollo y próximos pasos.
- [Texto para Google Docs](../strategy/BTC-EDU-para-Google-Docs.txt): copia del informe en texto plano.
- [Investigación y requisitos](../strategy/investigacion-y-requisitos.md): fuentes, costos, validación pendiente, criterios y decisiones.
- [Operación y bitácora](docs/operacion-y-bitacora.md): arranque, arquitectura, comandos, pruebas y registros fechados.

Para arrancar desde la raíz en PowerShell: `./dev.ps1`. Para arrancar únicamente la plataforma: `./dev-platform.ps1`. Consultar la guía técnica antes de configurar pagos o migrar datos.

Las evidencias permanecen en `docs/evidence` y los originales de CUBO+ en `../docs`. Las verificaciones históricas no acreditan una nueva ejecución ni validación con personas.
